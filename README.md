# HRMS — Human Resource Management System

Полнофункциональная HR-система на чистом PHP (без фреймворков) + MySQL/MariaDB.

## Возможности

- Аутентификация с ролями: **admin**, **hr**, **manager**, **employee** (сессии, bcrypt, CSRF-защита)
- Дашборд со статистикой (сотрудники, отделы, заявки на отпуск, посещаемость сегодня)
- Управление сотрудниками: список, поиск, фильтр по отделу, добавление, редактирование, деактивация
- Управление отделами
- Учёт посещаемости: отметка прихода/ухода, история, командный вид для HR/менеджеров
- Заявки на отпуск: подача, история, одобрение/отклонение
- Расчёт зарплаты по периодам с бонусами и удержаниями
- Управление ролями пользователей (только admin)
- Личный профиль с изменением телефона и пароля

## Технологии

- PHP 8+ (PDO, prepared statements — без ORM и фреймворков)
- MySQL / MariaDB
- Чистый HTML/CSS (без JS-фреймворков), шрифт DM Sans

## Установка

### 1. Требования

- PHP >= 8.0 с расширениями `pdo_mysql`, `gd` и `mbstring`
- MySQL или MariaDB >= 10.4
- Веб-сервер (Apache/Nginx) либо встроенный сервер PHP для разработки

### 2. Клонирование

```bash
git clone <your-repo-url> hrms
cd hrms
```

### 3. База данных

Создайте базу и загрузите схему:

```bash
mysql -u root -p < database/schema.sql
```

Схема автоматически создаёт базу `hrms_db`, все таблицы и учётную запись администратора:

- **Email:** admin@hrms.local
- **Пароль:** Admin123!

Опционально — тестовые данные (отделы, сотрудники, заявки, посещаемость):

```bash
mysql -u root -p < database/seed.sql
```
Пароль для всех демо-пользователей из seed.sql: `Demo123!`
(hr@hrms.local, manager@hrms.local, employee@hrms.local и т.д.)

### 4. Настройка подключения к БД

Откройте `config/config.php` и при необходимости измените:

```php
define('DB_HOST', '127.0.1.19');
define('DB_NAME', 'hrms_db');
define('DB_USER', 'root');
define('DB_PASS', 'ваш_пароль');
```

Для локальной отладки можно задать `HRMS_DEBUG=1`. По умолчанию подробные ошибки отключены.

Также можно задать значения через переменные окружения:
`HRMS_DB_HOST`, `HRMS_DB_NAME`, `HRMS_DB_USER`, `HRMS_DB_PASS`.

### 5. Запуск

Для локальной разработки:

```bash
php -S localhost:8000
```

Откройте http://localhost:8000 — вы будете перенаправлены на страницу входа.

Для production — укажите корень сайта на папку проекта в Apache/Nginx (документ-рут = корень репозитория, где лежит `index.php`).

Если сайт будет установлен не в корне домена (например, `https://site.com/hrms/`),
укажите это в `config/config.php`:

```php
define('BASE_URL', '/hrms');
```

## Роли и права доступа

| Раздел          | admin | hr | manager | employee |
|-----------------|:-----:|:--:|:-------:|:--------:|
| Дашборд         | ✅ | ✅ | ✅ | ✅ |
| Сотрудники (просмотр) | ✅ | ✅ | ✅ | ✅ |
| Сотрудники (добавление) | ✅ | ✅ | ❌ | ❌ |
| Сотрудники (редактирование employee) | ✅ | ✅* | ✅* | ❌ |
| Отделы          | ✅ | ✅ | ❌ | ❌ |
| Посещаемость (своя) | ✅ | ✅ | ✅ | ✅ |
| Посещаемость (команда) | ✅ | ✅ | ✅ | ❌ |
| Отпуска (подача) | ✅ | ✅ | ✅ | ✅ |
| Отпуска (одобрение) | ✅ | ✅ | ✅ | ❌ |
| Зарплата        | ✅ | ❌ | ❌ | ❌ |
| Пользователи/роли | ✅ | ❌ | ❌ | ❌ |

`*` HR может редактировать только пользователей с ролью `employee`; manager — только сотрудников своей команды. HR может менять оклад employee, manager оклад не меняет.

## Безопасность

- Пароли хранятся только в виде bcrypt-хешей (`password_hash`)
- Все SQL-запросы используют подготовленные выражения (PDO prepared statements)
- Все формы защищены CSRF-токеном
- Вывод данных экранируется через `htmlspecialchars` (функция `e()`)
- Деактивация сотрудника — «мягкое» удаление (сохраняется история посещаемости и зарплаты)
